已确认方向：把成功的 AI 用法整理为可复用资产，在团队和不同工具中使用，再验证改版效果。按独立批次实施；以下未勾选项尚未交付。

- [x] 结构化提炼目标、方法、变量、纠正、示例与待确认事项；长对话保留开头和结尾并提示省略。
- [x] 逐项编辑和选择保留内容，审阅后进入现有编辑器；导入草稿默认私有并沿用团队审批。
- [x] 模型不可用时明确降级为手动草稿，不能把请求成功等同于成功提炼。
- [x] 现有提示词可本地导出为标准 Skill ZIP，保留变量和已有元数据。
- [x] 目录导出保留所有已存文本文件及来源记录，拒绝路径穿越、文件覆盖及超限；明确同步快照与完整上游包的区别。
- [x] 覆盖转换、审阅后私有保存、鉴权、下载权限和 ZIP 解压的自动检查，以及手机/桌面浏览器组件流程验证。

本批不需要数据库迁移。ZIP 使用 `fflate`；同时显式声明了现有 ESLint 配置直接引用的开发依赖。
